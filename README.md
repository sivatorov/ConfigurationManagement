# Управление конфигурациями 1С

> Десктопное приложение для управления информационными базами 1С:Предприятие 8.3.

**Управление конфигурациями 1С** — это настольное приложение на платформе **.NET (WPF)**, которое заменяет стандартный список баз 1С и предоставляет удобный интерфейс для работы с информационными базами: запуск в различных режимах, группировка, избранное, теги, очистка кеша, импорт из стандартного файла `ibases.v8i` и экспорт/импорт списка баз в JSON.

## ✨ Возможности

### 🚀 Запуск информационных баз
- Запуск базы в режиме **«1С:Предприятие»** и **«Конфигуратор»**.
- Выбор типа клиента: **тонкий** / **толстый**.
- Выбор разрядности: **32-бит** / **64-бит**.
- Поддержка режима **«Веб-клиент»** (открывается в браузере).
- Автоматический поиск установленной платформы 1С (через `1CEStart.exe` или `1cv8.exe` / `1cv8x64.exe`).
- Поддержка файловых и клиент-серверных баз, аутентификации ОС и логина/пароля.
- **Конфигуратор параметров запуска** — визуальный выбор параметров командной строки 1С (`/UC`, `/DisableStartupMessages`, `/DisableSplash`, `/Debug`, `/UpdateCfg`, `/TestServer`, `/N`, `/P` и др.) с поддержкой произвольных параметров. При открытии корректно сопоставляет уже заданные параметры (включая значения с пробелами в кавычках) с элементами управления без учёта регистра.

### 🗂️ Управление списком баз
- **Табличное представление** базы (`DataGrid`): колонки «Наименование», «Версия платформы», «Тип подключения», «Режим запуска», «Сервер/База», а также кнопки «Избранное» (★) и «Закрепить» (📌).
- Добавление, редактирование и удаление информационных баз.
- **Группировка** баз по группам с возможностью сворачивания/разворачивания.
- **Избранное** — быстрый доступ к часто используемым базам (кнопка ★ и пункт контекстного меню). При активном фильтре «Только избранные» пустые группы (без избранных баз) автоматически скрываются.
- **Закрепление** баз — закреплённые базы отображаются отдельной группой **«Закреплённые»** вверху таблицы, независимо от их группы (кнопка 📌 и пункт контекстного меню).
- **Поиск** по имени, описанию, группе, версии платформы и тегам.
- **Теги** — гибкая категоризация баз, добавление тега прямо в строке названия (инлайн) и поиск по тегу.
- **Перетаскивание** групп для изменения порядка.
- Отображение даты последнего запуска и строки подключения, копирование строки подключения в буфер обмена.
- Выделение строки под курсором при правом клике, чтобы команды контекстного меню применялись к нужной базе.

### 🏷️ Группы
- Создание групп с **цветовой маркировкой** (выбор цвета через палитру).
- Описание групп.
- Управление группами в отдельном окне.

### 🔄 Импорт и экспорт
- **Импорт** списка баз из стандартного файла 1С `ibases.v8i` (автоматический поиск файла или выбор вручную) с переносом версии платформы, режима запуска и других параметров.
- **Экспорт** списка баз и групп в JSON-файл.
- **Импорт** списка баз из JSON-файла.
- **Очистка всего списка баз** — удаление всех баз и групп с подтверждением.
- **Автоматическое сопоставление ID базы** — при ручном создании базы ID 1С (GUID) автоматически подставляется из файла `ibases.v8i` по имени или строке подключения, что обеспечивает корректную точечную очистку кеша.

### 🧹 Очистка кеша 1С
- Очистка локального кеша платформы 1С для конкретной базы.
- Точечное удаление кеша по ID базы 1С (GUID из `ibases.v8i`).

### 🎨 Интерфейс
- **Светлая** и **тёмная** темы оформления.
- Сохранение настроек интерфейса между запусками (тема, избранное, группировка, свёрнутые группы).
- **Скрытие пустых групп** в режиме «Только избранные» — отображаются только группы, содержащие хотя бы одну избранную базу.
- Современный интерфейс на WPF с поддержкой MVVM.
- **Цветовая маркировка групп** — выбор цвета из палитры или произвольного цвета через RGB-слайдеры и HEX-поле, с автоматическим подбором контрастного цвета текста для читаемости.
- **Табличное представление списка баз** с современными стилями (`DataGrid`), заголовками колонок и адаптивной подсветкой строк/ячеек под обе темы.
- **Кастомные полосы прокрутки** — стилизованный скроллбар, который автоматически скрывается, когда не требуется.
- **Символы «+»/«−»** для сворачивания/разворачивания групп вместо chevron-стрелки.
- **Кнопка переключения группировки** с динамическим текстом («📁 Скрыть группы» / «📁 Показывать группы»).
- **Перетаскивание групп** для изменения порядка в списке.

## 🔧 Сборка и запуск

### Из исходного кода

```bash

git clone https://github.com/USERNAME/Configuration-Management.git
cd Configuration-Management

# Сборка проекта
dotnet build "Configuration Management/Configuration Management.csproj"

# Запуск
dotnet run --project "Configuration Management/Configuration Management.csproj"
```

Либо откройте файл решения `Configuration Management.slnx` в **Visual Studio 2022+** и запустите проект.

### 📦 Публикация автономного приложения

Проект настроен на публикацию в виде **автономного (self-contained) single-file** исполняемого файла для Windows x64. Для публикации выполните:

```bash
dotnet publish "Configuration Management/Configuration Management.csproj" -c Release
```

Результат появится в каталоге `publish/` — один исполняемый файл `Configuration Management.exe`, который не требует установки .NET Runtime на целевой машине.

## 💾 Хранение данных

Данные приложения сохраняются в каталоге `%APPDATA%\ConfigurationManagement`:

| Файл | Содержимое |
|------|------------|
| `infobases.json` | Список информационных баз |
| `groups.json` | Список групп с цветами |
| `settings.json` | Настройки интерфейса (тема, избранное, группировка) |

## 🔗 Работа с файлом `ibases.v8i`

Приложение взаимодействует со стандартным файлом списка баз 1С `ibases.v8i` (расположен в `%APPDATA%\1C\1CEStart\`):

- **Импорт** — считывает базы, группы, ID (GUID), версию платформы (`Version`), режим запуска (`App`), локаль (`Locale`), признак внешней базы (`External`), скорость соединения (`ClientConnectionSpeed`), признак веб-клиента (`WA`) и дополнительные параметры подключения (`AdditionalParameters`, сохраняются в параметры запуска базы). Добавляет новые базы и обновляет существующие.
- **Сопоставление ID** — при ручном создании базы приложение автоматически находит её ID в `ibases.v8i` по имени или строке подключения и подставляет его. Это обеспечивает корректную точечную очистку кеша 1С по GUID.
- **Очистка кеша** — использует ID базы (GUID) для удаления только соответствующего подкаталога кеша, а не всего каталога базы.

## 🧩 Архитектура

Приложение построено по паттерну **MVVM**:

- **Models** — описывают доменные сущности (информационные базы, группы, настройки подключения).
- **ViewModels** — содержат логику представления и команды, реализуют `INotifyPropertyChanged`.
- **Views (XAML)** — отвечают за отображение и привязку данных.
- **Services** — инкапсулируют работу с платформой 1С, файловой системой и хранилищем данных.
