Исправлено в версии **0.3.11.0** (Windows/WPF и Linux/Avalonia).

**Что было.** В окне «Скачивание версии платформы 1С» строки списка выбора с несколькими дистрибутивами одного типа выглядели одинаково — фактическое имя файла дистрибутива было видно только после выбора.

**Как исправлено:**

1. **Уникальные подписи видны сразу в списке** — [`PlatformDistributionOption.DisplayName`](Configuration%20Management/Services/PlatformDistributionPicker.cs) теперь включает фактическое имя файла дистрибутива, когда вариантов одного типа может быть несколько: уникальные строки видны сразу в списке выбора окна «Скачивание версии платформы 1С», а не только после выбора файла.
2. Выбор по `Url` и сортировка списка не изменились — изменился только текст подписи.

**Как проверить:**
1. Обновитесь до **0.3.11.0**, откройте «Скачивание версии платформы 1С».
2. Выберите версию с несколькими дистрибутивами одного типа — в списке сразу видны различающиеся подписи с именами файлов, до выбора.

Тесты: полный набор `dotnet test` зелёный (**2203**); сборка решения без ошибок.
