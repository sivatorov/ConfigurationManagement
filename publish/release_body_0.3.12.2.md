# v0.3.12.2 — Исправления по issues #334 и #352

Windows/WPF и Linux/Avalonia.

## Исправлено

- **Докачка цепочки обновлений работает (issue #352)** — «Да» в диалоге «Попробовать ещё
  раз?» (и ручное, и автоматическое по истечении отсчёта) теперь действительно
  перезапускает загрузку: повтор больше не блокировался собственным статусом «идёт
  загрузка» строки (рекурсивный вызов заменён циклом повтора); окно не закрывается
  «в никуда», недостающие файлы цепочки докачиваются — планировщик пропускает уже
  скачанное (Windows и Linux).
- **Диалог выбора файла версии учитывает галочку «Не повышать» (issue #352)** — при
  включённой галочке «Скачать» запрашивает страницу файлов ограниченной версии
  (3.1.x-максимум), а не глобальной последней: файлы кап-версии предлагаются всегда,
  даже когда она равна отображаемой «Последней версии»; предложение версии выше
  текущей невозможно.
- **Окно проверки обновлений не спрашивает «куда скачать» при уже выбранной папке
  (issue #352)** — одиночное скачивание сохраняется в выбранную папку цепочки без
  диалога; диалог выбора папки открывается только когда она не задана.
- **Индикация фонового скачивания платформы (issue #334)** — скачивание дистрибутива
  платформы 1С из окна «Обновление платформы 1С» («Только скачать» / «Скачать и
  установить») теперь регистрируется в общем менеджере фоновых загрузок и видно в
  индикаторе главного окна: прогресс, завершение и ошибка, работает отмена из
  индикатора — так же, как для окна «Скачивание версии платформы 1С» и цепочек
  обновлений (Windows и Linux).
- **Отмена выбора дистрибутива честно прерывает операцию (issue #334)** — «Отмена» в
  диалоге выбора варианта дистрибутива больше не приводит к диалогу «куда скачать»
  (раньше отмена подменялась «рекомендуемым» вариантом, и поток доходил до диалога
  сохранения); добавлен ключ локализации `Updates.Distribution.Cancelled` (ru/en).
