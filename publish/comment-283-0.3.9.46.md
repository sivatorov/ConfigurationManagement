Исправлено в версии **0.3.9.46**.

По обоим замечаниям:

**1. «Вновь добавленный не отображается в списке» — причина и исправление**

Причина: в окне свойств базы список автодополнения (`AvailableTags`) строился один раз при открытии окна из тегов, которые уже были у других баз. Новый тег, введённый прямо в этом окне, добавлялся только в теги базы, но не в список автодополнения — поэтому раскрытый выпадающий список его «не видел» до повторного открытия окна.

Исправлено:
- При добавлении тега он сразу же попадает и в список автодополнения текущего окна (без дублей, регистронезависимо, с сохранением сортировки по алфавиту) — `ConnectionSettingsViewModel.AddTag`.
- После сохранения базы панель фильтра тегов главного окна пересобирается на обеих платформах, и новый тег сразу появляется среди чипов (WPF: `RefreshTagFilterItems`, Linux/Avalonia: `RebuildTagFilters`).
- Дополнительно: при регистрации новой базы на Linux/Avalonia в окно свойств теперь передаются существующие теги всех баз (раньше параметр терялся, и автодополнение в этом сценарии не работало).

**2. «А можно список и вот тут тоже?» — выбор тега из списка на панели фильтров главного окна**

На панели «Теги» главного окна (там, где чипы тегов) под заголовком появился раскрывающийся список существующих тегов. Выбор тега из списка включает отбор по нему (как клик по чипу) — теперь не нужно вводить название вручную и можно не ошибиться в букве. Реализовано на обеих платформах — Windows/WPF и Linux/Avalonia.

**Как проверить**
1. Откройте окно правки базы → добавьте новый тег (Enter или кнопка «Добавить») → раскройте поле ввода тегов: только что добавленный тег уже есть в выпадающем списке.
2. Сохраните базу → на главном окне панель «Теги» показывает новый тег чипом, а в новом выпадающем списке под заголовком панели он тоже доступен для выбора (выбор фильтрует список баз по этому тегу).
