Исправлено в версии **0.3.9.68** (Windows/WPF и Linux/Avalonia).

**Что было сделано.**

Причина: целевая база лежит далеко вниз внутри длинной раскрытой группы. При
виртуализации списка (WPF `VirtualizingStackPanel` в режиме Recycling/Pixel,
Avalonia — реализованные контейнеры) контейнер строки за пределами видимой
области не создаётся никогда, поэтому повторные проходы поиска БЕЗ прокрутки
к месту цели бесполезны — переход «не происходил».

Теперь в сценарии «Найти в списке» (Ctrl+T / пункт контекстного меню):

1. **Windows/WPF** — если контейнер цели не найден, дерево принудительно
   материализуется: временно отключается виртуализация
   (`VirtualizingPanel.SetIsVirtualizing`) и выполняется раскладка — контейнеры
   создаются для всех строк, — затем выполняется прокрутка к цели, после чего
   виртуализация возвращается (позиция прокрутки сохраняется, цель остаётся
   в видимой области). В повторных проходах первым делом выполняется прокрутка
   к контейнеру домашней группы (`BringIntoView`); число попыток увеличено
   с 3 до 6.
2. **Linux/Avalonia** — добавлен метод `EnsureDataVisible` у `LeveledTreeView`:
   при отсутствии контейнера цели выполняется прокрутка к домашнему узлу
   (вверх/вниз к его заголовку) и итеративное движение к строке цели через
   внутренний `ScrollViewer` (шаг на экран за попытку); каждая повторная
   попытка `RevealFindInListAttempt` продолжает с места предыдущей. Число
   попыток увеличено с 3 до 8.

Обычные пересборки дерева (редактирование, таймер синхронизации) не затронуты:
принудительная материализация выполняется только в сценарии «Найти в списке».

**Как проверить:**

1. Установите версию **0.3.9.68** (Windows или Linux).
2. Создайте (или выберите существующую) группу с большим числом баз — например,
   несколько десятков баз в одной раскрытой группе.
3. Встаньте на любую базу внутри этой группы и нажмите **Ctrl+T** (или
   «Найти в списке» в контекстном меню) — переход к базе внутри группы работает.
4. Теперь встаньте на базу, которая находится НИЖЕ этой группы в общем списке
   (за пределами её раздела), и снова нажмите **Ctrl+T** — раньше переход
   «не происходил», теперь строка базы доводится до видимой области.
5. Повторите пункты 3–4 в обратном порядке и для баз из «Избранного» /
   «Недавних» — переход всегда ведёт к строке в общем списке.
