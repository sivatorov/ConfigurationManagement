Исправлено в версии **0.3.9.51**.

**Что изменилось**

1. **Выпадающий список убран с панели «Теги» главного окна** — на панели снова только чипы тегов (и кнопка сброса отбора). Отбор по тегам включается кликом по чипу, как было раньше.
2. **Выбор из существующих тегов добавлен в правку тегов в строке базы** — кнопка «+ тег» в строке базы открывает поле ввода, совмещённое с выпадающим списком существующих тегов (**Editable ComboBox**): можно выбрать готовый тег из списка или ввести новый текст и подтвердить Enter.

Реализовано на обеих платформах — Windows/WPF и Linux/Avalonia.

**Как проверить**

1. Панель «Теги» главного окна: под заголовком больше нет раскрывающегося списка — только чипы тегов; клик по чипу включает/выключает отбор.
2. В строке базы нажмите «+ тег»: раскроется поле ввода с выпадающим списком существующих тегов.
3. Выберите тег из списка (он добавится к базе) или введите новый текст и нажмите Enter; Esc отменяет, потеря фокуса сохраняет введённое.
4. Новый тег сразу отображается чипом в строке базы и на панели «Теги» главного окна (после сохранения).
