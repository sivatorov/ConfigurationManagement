# 0.3.10.1 — первый сводный выпуск

Начало перехода от детальных промежуточных сборок (`0.3.9.x`) к сводным выпускам
по основным версиям. Код выпуска полностью соответствует последней детальной
сборке серии `0.3.9` — [0.3.9.332] — новых изменений в коде нет.

## Изменено

- **Схема версионирования и CHANGELOG** — точечные исправления далее накапливаются
  в цикле, а для пользователей публикуются сводные выпуски (минорная версия
  меняется на стабильных точках); детальная история сборок `0.3.9.x` сохраняется
  в архиве [CHANGELOG.md](CHANGELOG.md).

## Ключевые изменения цикла 0.3.9.323–0.3.9.332 (кратко)

- Проверка обновлений конфигураций (F9): скачивание доходит до реального
  дистрибутива на портале 1С (якоря по подписи, `transfer_file` вне href,
  расширение из query), цепочки обновлений «снизу вверх»/«оптимальный»
  и «Скачать цепочку» (issue #352).
- Обновление платформы 1С (Ctrl+F9): раскладка окна, поддержка
  `*_updsetup*`-архивов и вложенных zip, диалог «Удалить старые версии…»
  с чеклистом (issue #334).
- Скачивание версии платформы 1С: декодирование HTML-сущностей в каталоге
  `releases.1c.ru`, поиск по дереву версий, «Свернуть все»/«Развернуть все»,
  выбор типа дистрибутива (issue #330).
- Монитор серверов 1С: быстрый поиск `rac`, имя кластера вместо «ключа»,
  честный статус автообновления, поддержка rac 8.5.4.1878 (issue #324).
- Сброс отбора по тегу при выключении показа тегов (issue #354);
  двойной клик по колонкам «№ релиза»/«Конфигурация» открывает свойства
  базы на вкладке «Платформа» (issue #355);
  починка потери папок при импорте `ibases.v8i` (issue #351).
