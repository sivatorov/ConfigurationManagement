## [0.3.9.44] — 2026-09-24

Реализовано пожелание из issue [#286](https://github.com/sivatorov/ConfigurationManagement/issues/286).

### Новое

- **Задания по расписанию ([#286](https://github.com/sivatorov/ConfigurationManagement/issues/286))** —
  резервное копирование, обновление конфигурации ИБ и обновление самого приложения
  по расписанию (время «ЧЧ:ММ» + выбор дней недели). Задания выполняются фоновым
  планировщиком, пока приложение запущено; результат каждого запуска сохраняется в задании.
  1. **Типы заданий**: «Резервная копия» (существующий сценарий + база), «Обновление
     конфигурации ИБ» (загрузка `.cf` через `/LoadCfg` + `/UpdateDBCfg`),
     «Копия → обновление конфигурации» (последовательно: сначала копия, при успехе —
     обновление) и «Обновить приложение» (GitHub Releases, без диалогов).
  2. **Планировщик** (`SchedulerService`): периодическая проверка каждые 30 секунд,
     выполнение строго последовательно (одна операция 1С за раз), журналирование;
     пропущенные запуски не «догоняются», есть кнопка «Выполнить сейчас».
  3. **UI**: окно «Задания по расписанию» (список, статус последнего запуска) и форма
     редактирования; точка входа — подменю «Утилиты» верхней панели. На обеих платформах
     (Windows/WPF и Linux/Avalonia). Новые ключи локализации `Schedule.*` в ru/en.
  4. **Обновление конфигурации ИБ**: новая пакетная операция конфигуратора
     `DesignerBatchOperation.LoadCfg` (`/LoadCfg"file.cf" /UpdateDBCfg`) на обеих платформах.
  5. **Хранилище заданий**: отдельные JSON-файлы в `<DataDir>/schedules/*.task.json`;
     чистая логика расписания покрыта юнит-тестами (весь набор — 93 теста).

### Файлы для установки

- **Windows (x64)**: `ConfigurationManagement.exe` (single-file, self-contained).
- **Linux (x64)**: `ConfigurationManagement-linux-x64` (single-file, self-contained; при необходимости `chmod +x`).
