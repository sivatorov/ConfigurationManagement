Исправлено в версии **0.3.9.331** (Windows/WPF и Linux/Avalonia).

**Причина.** Скачивание работало с адресом страницы, а не с адресом дистрибутива:

1. Обычная кнопка «Скачать» передавала в загрузчик адрес **каталога релизов** (`releases.1c.ru/project/<ник>` — страница со списком релизов), а не адрес файлов последней версии, — скачивалась HTML-страница списка релизов, сохранённая как «.zip».
2. Для шагов цепочки (и в том числе после перехода на страницу файлов версии) сохранялся ответ **промежуточной страницы скачивания конкретного файла** — её адрес на releases.1c.ru тоже заканчивается на «.zip», поэтому файл выглядел правдоподобно, но внутри была страница «скачивания этого файла».

**Как исправлено** ([`OneCUpdatesService.cs`](Configuration%20Management/Services/OneCUpdatesService.cs)) — скачивание («Скачать» и «Скачать цепочку») теперь разрешает **конечный адрес дистрибутива**, проходя по цепочке страниц: каталог релизов → страница файлов релиза (`version_files`) → промежуточная страница скачивания файла → ссылка `transfer_file`/прямая ссылка на архив:

1. Каждый HTML-ответ анализируется, и из него берётся следующая ссылка на пути к дистрибутиву (приоритет: `setup*.zip` → полный `*.zip` → `setup*.exe`/`*.rar`/`*.7z` → `1cv8.cf` → `transfer_file` → `version_files`); сохраняется только бинарный контент. Авторизация на portal.1c.ru используется та же (`OneCUpdatesLoginFlow`).
2. Защита от зацикливания: посещённые адреса не запрашиваются повторно, максимум 5 переходов; страница входа вместо дистрибутива — честная ошибка, файл не создаётся.
3. Итоговый файл получает расширение конечного адреса: если дистрибутив оказался «.rar»/«.exe»/«.7z», имя файла не остаётся «.zip».
4. **Окно выше** (замечание 1): окно проверки обновлений выше по умолчанию (660), а при появлении строк в таблице вариантов цепочки автоматически поднимается до ~760 (не выше рабочей области экрана) — 2–3 строки «№ / Список версий» видны без прокрутки. Обе версии окна: WPF ([`UpdateCheckWindow.xaml`](Configuration%20Management/Views/UpdateCheckWindow.xaml)) и Avalonia ([`UpdateCheckWindow.Avalonia.cs`](Configuration%20Management/Views/UpdateCheckWindow.Avalonia.cs)).

**Как проверить:**
1. Обновитесь до **0.3.9.331**, откройте «Проверка обновлений» (F9) для базы с более свежим релизом.
2. Нажмите «Скачать» — в файле должен оказаться реальный дистрибутив (архив), а не страница со списком релизов; расширение файла соответствует скачанному дистрибутиву.
3. «Скачать цепочку» — каждый файл цепочки является дистрибутивом своей версии, а не страницей его скачивания.
4. При появлении таблицы вариантов окно поднимается — 2–3 строки таблицы видны сразу.

Тесты: полный набор `dotnet test` зелёный (**1996**), кросс-сборка Linux (`dotnet build -p:BuildLinux=true`) без ошибок. Новые: `OneCUpdatesDistributionResolutionTests` (+14: прохождение цепочки «каталог → version_files → страница файла → transfer_file» на fake-HTTP-стеке, разрешение реального файла, защита от зацикливания и страницы входа, подстановка расширения, выбор следующей ссылки).
