Исправлено в версии **0.3.11.0** (Windows/WPF и Linux/Avalonia).

**Что было.** Поля «Поле», «Область» и «Режим» в окне «Замена строк подключения» показывали ключи локализации вместо значений — причина в отсутствии ключей во встроенном словаре при устаревшем внешнем файле языка `Languages/ru.json`.

**Как исправлено:**

1. **Ключи добавлены во встроенные словари** — `ConnectionReplace.FieldLabel`/`ScopeLabel`/`ModeLabel` («Поле», «Область», «Режим») добавлены во встроенные словари ru/en — при устаревшем внешнем файле языка поля окна показывают значения, а не ключи.
2. **Аудит закреплён регресс-тестом** — покрытие всех ключей `ConnectionReplace.*` во встроенных словарях проверяет [`ConnectionReplaceLocalizationTests`](ConfigurationManagement.Tests/ConnectionReplaceLocalizationTests.cs).

**Как проверить:**
1. Обновитесь до **0.3.11.0** (внешний файл `Languages/ru.json` можно оставить как есть — устаревший).
2. Откройте «Утилиты → Операции → Замена строк подключения» — подписи «Поле», «Область», «Режим» отображаются значениями, а не ключами.

Тесты: полный набор `dotnet test` зелёный (**2203**); сборка решения без ошибок.
Релиз публикуется, будет доступен на странице Releases в ближайшее время. Пожалуйста, проверьте — если проблема воспроизведётся, напишите здесь.
