Исправлено в версии **0.3.9.57** (Windows/WPF и Linux/Avalonia).

**Что было исправлено.** Окно создания/редактирования группы открывалось на вкладке «Цвет» — она
была помечена активной по умолчанию (замечание к issue #249). При добавлении новой группы это
неудобно: имя — первое, что нужно ввести, а цвет ярлычка можно выбрать и позже.

**Что сделано:**

- При открытии окна добавления/редактирования группы активна вкладка «Основные» с полем «Имя».
- Фокус при открытии окна сразу стоит на поле имени — можно печатать имя без лишнего щелчка
  (при редактировании существующей группы имя выделяется целиком).
- Для служебных узлов «Без группы»/«Закреплённые» поведение прежнее: вкладка «Основные» там
  скрыта, поэтому по-прежнему открывается «Цвет».
- Исправлено на обеих платформах — Windows/WPF и Linux/Avalonia.

**Как проверить:**

1. Установите версию **0.3.9.57**.
2. Добавьте группу (контекстное меню → «Добавить группу») — окно открывается на вкладке
   «Основные», курсор уже в поле «Имя».
3. Введите имя и сохраните — группа создана; цвет ярлычка при желании выбирается на вкладке «Цвет».
4. Откройте редактирование существующей группы — окно также открывается на вкладке «Основные».
