# v0.3.9.328 — Цепочки обновлений конфигурации для базы (issue #352)

Windows/WPF и Linux/Avalonia.

## Что нового

- **Цепочки обновлений конфигурации для базы (issue #352)** — окно «Проверка
  обновлений» (F9):
  - сводка «Текущая версия | Последняя версия | Статус» в один ряд;
  - проверка возможности прямого обновления текущей версии до последней по колонке
    «Список версий» таблицы релизов на `releases.1c.ru`;
  - таблица вариантов цепочки («№» и «Список версий»): вариант «снизу вверх»
    (максимальный шаг с текущей версии) и вариант «оптимальный» (минимум прыжков),
    показываемый при отличии;
  - кнопка «Скачать цепочку»: выбор каталога и последовательная загрузка всех
    версий выбранного варианта с прогрессом «какой файл скачивается и сколько
    осталось»;
  - при отсутствии данных о совместимости — прежнее поведение (только последняя
    версия) с понятным статусом.

## Тесты

Полный набор `dotnet test` зелёный (**1941**); кросс-сборка Linux
(`dotnet build -p:BuildLinux=true`) без ошибок.

## Сборка

- Windows: single-file self-contained WPF (`net10.0-windows`, win-x64).
- Linux: single-file self-contained Avalonia (`net10.0`, linux-x64), .deb и AppImage.
