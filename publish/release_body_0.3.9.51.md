## [0.3.9.51] — 2026-09-25

Промежуточный выпуск: исправления по issues
[#289](https://github.com/sivatorov/ConfigurationManagement/issues/289),
[#285](https://github.com/sivatorov/ConfigurationManagement/issues/285) и
[#283](https://github.com/sivatorov/ConfigurationManagement/issues/283).

### Исправлено

- **Таймаут проверки доступности клиент-серверных баз из настроек ([#289](https://github.com/sivatorov/ConfigurationManagement/issues/289))** —
  жёсткие 8 секунд на базу при проверке доступности заменены настройкой «Таймаут определения
  свойств конфигурации» (по умолчанию 30 секунд, минимум 1 секунда). Если клиент-серверные базы
  подключаются дольше 30 секунд, увеличьте значение в Настройки. Обновлены подсказка кнопки
  проверки и README (раздел «Проверка доступности баз»).

- **«Найти в списке» (Ctrl+T): строка базы гарантированно выделяется и попадает в видимую область ([#285](https://github.com/sivatorov/ConfigurationManagement/issues/285))** —
  переход к базе в общем списке работает для баз в свёрнутых группах в конце длинного списка:
  устранены неснятые ключи свёрнутых групп при вызове из Избранного/Закреплённых, добавлен
  «добирающий» проход при ненайденном контейнере строки (Windows/WPF) и явная прокрутка контейнера
  в видимую область (Linux/Avalonia). На обеих платформах.

- **Панель «Теги» снова только с чипами; выбор тегов — в правке тегов в строке базы ([#283](https://github.com/sivatorov/ConfigurationManagement/issues/283))** —
  раскрывающийся список убран с панели «Теги» главного окна (отбор — кликом по чипу), а выбор из
  существующих тегов добавлен в поле правки тегов в строке базы (кнопка «+ тег») — Editable ComboBox:
  выбор готового тега из списка или свободный ввод нового. На обеих платформах.

### Файлы для установки

- **Windows (x64)**: `ConfigurationManagement.exe` (single-file, self-contained).
- **Linux (x64)**: `ConfigurationManagement` (single-file, self-contained; при необходимости `chmod +x`).
