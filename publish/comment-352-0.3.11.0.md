Исправлено в версии **0.3.11.0** (Windows/WPF и Linux/Avalonia).

**Как исправлено:**

1. **Кнопка «Скачать»: выбор дистрибутива** — для релиза, у которого дополнительный файл — расширение конфигурации (`.cf`), скачивание больше не заканчивается WARN «В ответе не найдена ссылка на дистрибутив»: [`OneCUpdatesService.GetReleaseFileChoicesAsync`](Configuration%20Management/Services/OneCUpdatesService.cs) открывает страницу файлов версии и предлагает выбор «Дистрибутив обновления» / «Полный дистрибутив» с разрешёнными конечными адресами; диалог появляется только когда доступны оба варианта (один — скачивается сразу), расширение имени сохранения берётся из выбранного файла.
2. **Папка сохранения цепочки запоминается** — выбранный каталог сохраняется в настройках ([`AppSettings.UpdateChainFolder`](Configuration%20Management/Models/AppSettings.cs)), при следующем скачивании цепочки диалог открывается в нём; путь выводится над таблицей цепочки и добавлена кнопка «Открыть» (проводник/файловый менеджер).
3. **Диалог «Попробовать ещё раз?» при ошибках скачивания** — вместо простого предупреждения открывается окно с вопросом повтора и 60-секундным обратным отсчётом на кнопке «Да» («Да (57)», по достижении нуля — автоматический «Нет»); повтор использует докачку: `.download`-файлы и счётчик «Скачивается N из M» сохранены, докачивается только недостающее ([`UpdateChainDownloadPlanner.SelectPendingSteps`](Configuration%20Management/Services/UpdateChainDownloadPlanner.cs)).

**Как проверить:**
1. Обновитесь до **0.3.11.0**, откройте «Проверка обновлений» (F9).
2. Нажмите «Скачать» на релизе с `.cf`-дополнительным файлом — появится выбор «Дистрибутив обновления» / «Полный дистрибутив».
3. «Скачать цепочку» — выбранная папка запоминается и подставляется в следующий раз; путь виден над таблицей цепочки, кнопка «Открыть» открывает папку.
4. При обрыве сети — диалог «Попробовать ещё раз?» с 60-секундным отсчётом; «Да» докачивает только недостающие файлы.

Тесты: полный набор `dotnet test` зелёный (**2203**); сборка решения без ошибок.
