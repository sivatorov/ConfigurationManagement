Исправлено в версии **0.3.9.329** (Windows/WPF и Linux/Avalonia).

**Причина.** При выключении «Показывать теги в строке» сеттер `ShowTags` в WPF-части ([`MainViewModel.Display.cs`](Configuration%20Management/ViewModels/MainViewModel.Display.cs)) явно вызывал `ClearTagFilters` — вместе с чипами фильтров сбрасывался и сам отбор по тегу, из-за чего список выходил из «Найденного». На Avalonia такой привязки не было — поведение платформ различалось.

**Как исправлено.** Сброс фильтров при переключении показа тегов убран: WPF-чипы активных фильтров скрываются декларативно (стиль `MainWindow.xaml`), а сам отбор по тегу сохраняется — паритет с Avalonia. Показ тегов и отбор по тегам теперь действительно независимы.

**Как проверить:**
1. Установите **0.3.9.329**.
2. Включите показ тегов в строках, включите отбор по одному из тегов — список уходит в «Найденное».
3. Выключите показ тегов в строке — отбор сохраняется, список остаётся отфильтрованным; чипы фильтра не мешают, потому что скрыты вместе с колонкой тегов.

Тесты: полный набор `dotnet test` зелёный (**1966**), кросс-сборка Linux (`dotnet build -p:BuildLinux=true`) без ошибок.
Файлы для установки — на странице релиза [v0.3.9.329](https://github.com/sivatorov/ConfigurationManagement/releases/tag/v0.3.9.329).
