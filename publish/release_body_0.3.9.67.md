## [0.3.9.67] — 2026-09-26

Выпуск: компактный режим на Windows теперь сжимает и основную строку списка баз —
внутренние иконки, теги и шрифты масштабируются по образцу Linux-версии, и строка
визуально опускается до высоты строки группы ([#296](https://github.com/sivatorov/ConfigurationManagement/issues/296)).

### Исправлено

- **Компактный режим на Windows сжимает основную строку списка баз
  ([#296](https://github.com/sivatorov/ConfigurationManagement/issues/296))** —
  ранее компактность строки задавалась только внешним `Padding/Margin` (~4 пикселя),
  а её высоту определяли внутренние элементы: иконка статуса (14), иконки
  избранного/закрепления (14), кнопки действий (15) и строка тегов (16). Разница
  между режимами была практически незаметна, в отличие от Linux-версии
  (`UiMetrics.Scale=0.8`). Теперь в компактном режиме сжимается вся внутренняя
  структура строки базы:
  - иконка статуса, избранного и закрепления — 14 → 12;
  - иконки кнопок действий строки (запуск/конфигуратор/очистка кэша) — 15 → 13;
  - бейджи тегов и кнопка «Добавить тег» — 16 → 14, иконка «Добавить тег» — 11 → 10;
  - бейдж горячей клавиши избранного — `MinWidth` 16 → 14.
  Вместе с уже работавшим масштабированием отступов и шрифтов
  (`ThemeManager.ApplyCompactTree`: отступы ×0.7, шрифты ×0.9) основная строка
  визуально опускается до высоты строки группы, список становится заметно плотнее.
  Выключение режима возвращает прежние размеры; шапка окна и кнопки управления
  остаются компактными. Правки только в WPF-разметке — Avalonia (Linux)
  не затрагивалась.

### Файлы для установки

- **Windows (x64)**: `ConfigurationManagement.exe` (single-file, self-contained).
- **Linux (x64)**: `ConfigurationManagement` (single-file, self-contained; при необходимости `chmod +x`).
