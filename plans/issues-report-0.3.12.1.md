#### Комментарий 10 — sivatorov, 2026-10-09T11:59:57Z (исправление 0.3.10.2: additional_file как дистрибутив, докачка `UpdateChainDownloadPlanner`, временное расширение `.download`)

> Исправлено в версии **0.3.10.2** (Windows/WPF и Linux/Avalonia).
>
> 1. **`additional_file` как конечный дистрибутив** — адрес `additional_file?…` распознаётся файловым эндпоинтом, ответ сохраняется как файл с расширением из query `path` (`.cf`); HTML-страница ошибки файлом не сохраняется.
> 2. **Докачка цепочки** — `UpdateChainDownloadPlanner` на старте определяет скачанные файлы (существует и размер > 0), качает только недостающие; счётчик «Скачивается X из Y» только по реально скачиваемым.
> 3. **Временное расширение `.download`** — файл пишется во `<имя>.download`, по успеху атомарно переименовывается, при сбое удаляется.
> 4. **Устойчивость цепочки** — сбой одной версии не останавливает остальные.
