**Файлы**:
- `Configuration Management/Services/OneCPlatformCatalogParser.cs` — новые правила
  разбора: получить/сохранить образец HTML страницы 8.5.1.1522 (и 8.3.27.2325),

  с иным атрибутом href или JavaScript-навигацией), добавить распознавание;
  декодирование HTML-сущностей уже есть — расширить при необходимости.
- `Configuration Management/Services/PlatformUpdateService.cs` — при 0 распознанных
  файлов сохранять тело ответа в файл диагностики рядом с журналом (для будущих

  `ConfigurationManagement.Tests/PlatformUpdateServiceTests.cs` — фикстуры с
  фрагментами реальной разметки 8.5 и новым регресс-тестом.

**Ожидаемый объём**: средний (парсер + тесты). **Порядок**: сначала добыть HTML
страницы (пользователь уже прислал диагностику с URL и длиной), затем парсер,
затем тесты.
